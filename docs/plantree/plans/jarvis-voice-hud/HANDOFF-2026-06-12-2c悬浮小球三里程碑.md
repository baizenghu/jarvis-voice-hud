# ⑥ 环境约束与 gotcha(新增/变更,旧约束见早上 HANDOFF ⑥)

- **GPU 预算(12G)是硬约束**:cosyvoice 5.6G + whisper 2G + bge-reranker 1.3G ≈ 9G。
  **不要再往这块卡加模型**;新服务先 `nvidia-smi` 看余量。
- **CosyVoice 服务必须用带锁版**(`cosyvoice_server.py` `_infer_lock`);它非线程安全,无锁并发=状态污染。
- **hermes tts_tool 的 command 型在 Windows 走 cmd(`shell=True`),不走 Git Bash**——配置里别写 env/bash 语法;
  桥接参数化(`cosyvoice_say.py <in> <out> [api_base]`,自带 ProxyHandler({}) 绕代理)。
- **上游 hermes 无 voice.* RPC**:非 fork 部署必须经 `dev_server.py`(启动注册 `gateway_voice_patch`)。
- **whisper_api 必须用 `HERMES_HOME=~/.hermes-stt` 启动**(主配置 stt=openai 指向它自己,不隔离会死循环)。
- 服务启动命令(中心):
  - whisper:`HERMES_HOME=~/.hermes-stt HOST=0.0.0.0 PORT=8010 nohup .venv/bin/python hud-app/whisper_api.py &`
  - cosyvoice:`nohup bash hud-app/start_cosyvoice.sh &`
  - 40445:`HOST=0.0.0.0 PORT=40445 SSL_CERTFILE=hud-app/.certs/cert.pem SSL_KEYFILE=hud-app/.certs/key.pem nohup .venv/bin/python hud-app/dev_server.py &`
- 家里网关:`HERMES_HOME=/home/baizh/hermes-home HOST=127.0.0.1 PORT=8765 nohup /home/baizh/hermes-agent/.venv/bin/python /home/baizh/hermes-agent/hud-app/dev_server.py &`
- Windows:网关 `D:\hermes-dev\hud-app\start_gateway.bat`(CRLF!);小球 `cd D:\hermes-dev\hud-app\shell && npm run tauri:dev`。
- tar-over-ssh 同步(中心→Windows/家里)是标准发布通道;Windows bat 文件必须 CRLF。
