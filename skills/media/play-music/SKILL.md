# 网页放歌(歌曲宝 + clawtouch)

用户想听歌时,在本机 Linux 桌面的 **Chrome** 里用 **歌曲宝(gequbao.com,免费、免登录、歌库较全)** 播放。
**分工**:`terminal` 工具做确定性导航(开浏览器、直达搜索页),`mcp_clawtouch_hid_*`(截屏 + 鼠标)做点击。
注意:音乐在真实浏览器里出声(系统声卡),不是在 HUD 里——HUD 不会跟着跳,这是正常的。

## 放歌步骤
1. **打开搜索结果页**(歌名直接放进 URL,避开 HID 打中文的 IME 问题)。用 `terminal` 执行
   (**必须带 `DISPLAY=:0`**,默认浏览器是 chrome):
   ```
   DISPLAY=:0 xdg-open "https://www.gequbao.com/s/周杰伦 晴天"
   ```
   把"周杰伦 晴天"换成用户要的歌(可带歌手,提高命中)。Chrome 会自动编码 URL。
2. 等约 2 秒,调 `mcp_clawtouch_hid_screenshot` 截屏,看搜索结果页。
3. 用视觉找到**第一条匹配的歌曲结果**,用 `mcp_clawtouch_hid_click` 点它,进入歌曲页。
4. 再截屏,找到**播放按钮(▶ 或"播放")**,点击它。
5. 截屏确认已在播放(进度条在动 / 播放键变暂停)。然后用一句口语回复用户,例:"好,放晴天。"

## 停止 / 换歌
- **停止**:截屏找到暂停键点击;或关掉那个标签页。优先点暂停。
- **换歌**:回到步骤 1,用新歌名重新打开搜索页。

## 要点 / 防坑
- **每一步先截屏、用视觉定位再点**,不要凭记忆点固定坐标——歌曲宝布局会变、可能有广告浮层。
- 若有广告弹窗/新标签遮挡:先截屏看清,点关闭(×)再继续。
- 这是在操作本机桌面的真实鼠标,动作要稳;点击后截屏确认结果,不对就重试。
- 找不到结果或页面异常时,如实告诉用户,别假装放了。
- 普通对话(不是听歌请求)不要触发本流程。
